# Wizard Integration

Beim Übernehmen eines Hardware-Proposals wird zunächst der HardwareNode kanonisch angelegt. Ist er nach expliziter Auswahl oder Device-Class-Policy adressierbar, vergibt der zentrale Allocator unmittelbar die Adresse. Erst danach werden Interfaces, Nachrichten, Signale und Routing aufgebaut.

Der Hardware-Schritt zeigt Addressability, optionale manuelle Adresse und Namespace. KI-Vorschläge dürfen die Addressability beeinflussen, aber keine Nummer festlegen.
