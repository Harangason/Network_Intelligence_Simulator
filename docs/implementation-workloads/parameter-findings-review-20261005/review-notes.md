# Parameter findings review

## Cause
The parameter form displayed profile fallback values and saved scenario assumptions under one unsaved/unverified notice. Proposal findings were captured at preview time and their navigation lost technology and field context. The native capacity check deliberately excludes ASSUMED rates from confirmed evidence. The check was not replaced or weakened.

## Change
Current model review reuses the proposal capacity validator, scoped to the active project. The parameter page shows current findings grouped by technology and links to actual schema fields and physical ports. Native finding details are retained. Proposal links preserve project, technology and proposal context; applied findings are explicitly historical. Saved scenario assumptions remain labeled ASSUMED and do not become hardware facts. Network rates can be explicitly confirmed only for selected matching networks; unsaved parameter drafts block that operation to preserve user input. Native LIN requirements remain visible after confirming only a rate.
