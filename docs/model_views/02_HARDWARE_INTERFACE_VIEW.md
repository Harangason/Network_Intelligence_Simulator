# Hardware Interface View

`Hardware Interface` is a dedicated model-view resource backed by `HardwareNetworkInterface`.

It shows:

- Hardware Node
- Interface Name
- Technology
- Controller / Channel
- Physical Port
- Network
- Bitrate and Data Bitrate
- Message Count
- Static Load and Runtime Load
- Reserve
- Status

The tab is placed between `Hardware-Knoten` and `Funktionen`.
