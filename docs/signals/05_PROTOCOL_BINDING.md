# Protocol Binding

Protocol binding connects the semantic signal to a concrete network technology.

Supported examples:

- CAN and CAN_FD
- LIN
- Ethernet based industrial or vehicle networks
- imported trace formats such as BLF, ASC and PCAP
- system specific formats such as ARXML, AXML, DBC, CSV, XLSX, JSON and YAML

Gateway ports can represent separate network segments. Shared bus ports should be grouped when they are physically the same segment.
