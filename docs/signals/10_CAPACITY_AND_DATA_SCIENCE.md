# Capacity And Data Science

Capacity, timing and Data Science views must show why a warning exists.

Required user-facing evidence:

- warning origin by tab or detail view
- affected network, route, message and signal
- sender and participants when available
- system frame or system cluster
- semantic type and bit requirement status
- concrete proposal or reason why no proposal is possible

Data Science must not remain empty when capacity overload exists. It should learn from failed cases and propose network distribution options.
