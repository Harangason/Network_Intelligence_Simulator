# Signal Behavior Models

Unterstuetzt werden:

- `CONSTANT`
- `STEP`
- `RAMP`
- `LINEAR`
- `SINE`
- `TRIANGLE`
- `SAWTOOTH`
- `PULSE`
- `RANDOM_WALK`
- `BOUNDED_RANDOM`
- `STATE_DEPENDENT`
- `FORMULA`
- `LOOKUP_TABLE`
- `EXTERNAL_SERIES`
- `PHYSICS_MODEL`

`BOUNDED_RANDOM` springt nicht mehr frei ueber den kompletten Wertebereich, sondern nutzt eine reproduzierbare Random-Walk-Logik mit vorherigem Signalzustand.
