# Physical Plausibility

Physikalische Signale werden begrenzt durch:

- `minimum` / `maximum`
- `max_rise_rate`
- `max_fall_rate`
- `initial_value`
- zyklische Vorwerte im Runtime State
- kontrollierte Noise-Modelle

Beispiel: Eine Temperatur springt nicht von 20 auf 135 Grad, sondern steigt mit begrenzter Rate in Richtung Betriebsziel.
