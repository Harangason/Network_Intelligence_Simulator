# Simulation Context

`SimulationContext` enthaelt:

- `current_time`
- `dt`
- `seed`
- `scenario`
- `system_state`
- `function_states`
- `signal_values`
- `commands`
- `faults`
- `environment`
- `routing_context`
- `network_context`

Damit koennen spaetere Behavior-Modelle fachliche Systemzustaende nutzen, ohne eine zweite Timeline zu bauen.
