# TransportUnit model

Fields: `id`, `technology_binding_ref`, `transport_unit_type`, `producer_ref`, `consumer_refs`, `payload_elements`, `payload_size`, `timing`, `identifier`, `priority`, `qos`, `status`, and `provenance`.

Supported unit vocabulary includes frames, messages, telegrams, PDUs, packets, words, datagrams, topic samples, services, register blocks, process data, streams, and file blocks.
