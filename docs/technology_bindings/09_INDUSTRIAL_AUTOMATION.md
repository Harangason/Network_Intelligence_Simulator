# Industrial automation

Registered technologies include PROFINET, EtherCAT, EtherNet/IP, Modbus TCP/RTU/ASCII, PROFIBUS DP/PA, DeviceNet, CC-Link, Sercos III, POWERLINK, IO-Link, OPC UA, MQTT/Sparkplug B, and safety profiles.

PLC/SPS is a hardware type. The PLC Wizard model type recommends an explicit subset and never activates every interface automatically.
