# Test strategy

Automated tests verify layer ordering, resolver capabilities, invalid payload/interface handling, implementation status enforcement, registry-backed Wizard generation, and API catalog exposure.

Cross-technology coverage binds the same temperature semantic to CAN-FD, Modbus TCP, PROFINET, and DDS. PLC coverage validates hardware capability filtering. Browser E2E verifies selection, submission, proposal generation, and review rendering for newly created project model types.
