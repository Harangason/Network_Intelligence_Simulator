2.2.1. MIPI CSI/DSI Transmitter Clocking Overview 
Clocks shown in Figure 2.3 and Figure 2.4 are typically generated using an external PLL. For more details of each clock, 
refer to the Signal Description section. 
Table 2.1. MIPI CSI/DSI Transmitter Operating Frequency Details and Requirements 
Clock Operating Frequency Details and Requirements 
ref_clk_i The operating frequency of this clock can be set using the Reference Clock Frequency (MHz) 
attribute. Supported values are 60 MHz and up to 200 MHz, depending on the device 
configuration. 
pll_clkop_i This is the 0-degree phase output of an external PLL. This clock depends on the Line Rate Per 
Lane (Mbps). 
Example: 
pll_clkop_i = (Line Rate Per Lane (Mbps)/2)
