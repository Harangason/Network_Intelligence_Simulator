axis_vid_clk_i When Unified Video Streaming Interface (UVSI) is checked:  
The axis_vid_clk_i frequency must be selected such that the average input pixel rate does not 
exceed the effective throughput of the MIPI transmitted over time. If axis_vid_clk_i is higher 
than the recommended frequency from the formula below, the upstream provides pixel data 
faster than the IP can transfer the data into the byte domain. To avoid FIFO overflow, sufficient 
horizontal blanking and/or line buffer depth must be provided. Otherwise, the IP asserts 
backpressure on the UVSI interface. 
The operating frequency is recommended to be derived based on the following formula to 
ensure correct and reliable operation. 
 
axis_vid_clk_iMHz = ((Number of D-PHY Lanes × PHY Data Width) / (Number of Pixel per Clock 
(PPC) × BPP1)) × Actual Byte Clock Frequency (MHz) 
 
Example 1: 
Line Rate Per Lane (Mbps) = 1,500 
PHY Data Width = 8 
Number of D-PHY Lanes = 4 
Number of Pixel per Clock (PPC) = 4 
Enable RGB888 Color Format = checked (BPP = 24) 
Actual Byte Clock Frequency (MHz) = 187.5 MHz 
 
axis_vid_clk_iMHz = ((4 × 8) / (4 × 24)) × 187.5 = 62.5 MHz 
 
When MIPI Byte Streaming Interface (MBSI) is checked:  
The operating frequency is recommended to be equal to Actual Byte Clock Frequency (MHz) to 
ensure correct and reliable operation. When axis_vid_clk_i is higher than the Actual Byte Clock 
Frequency (MHz), sufficient horizontal blanking and/or byte buffer depth must be provided to 
prevent buffer overflow.

2.2.1.1. MIPI CSI/DSI Transmitter Edge Clock Sharing 
This edge clock sharing mode is intended for designs that instantiate multiple Soft D -PHY TX blocks within the same 
bank and need to conserve edge clock resources, provided all instances operate at the same bit rate. Edge clock is the 
high-speed per-bank clock network in Lattice FPGAs that drives DDR I/O elements and synchronizes PHY data 
transitions. The Soft D-PHY TX uses FPGA DDR elements together with edge clock synchronizer and divider resources to 
generate the edge-aligned transmit clock. When Edge Clock Mode is External, the IP does not instantiate the edge clock 
synchronizer and divider. Instead, the ports required to drive the DDR path such as the byte clock, edge clock sync 
clock, reset, and readiness indicators, are exposed as top -level inputs. These signals must be connected to the 
corresponding outputs of another D-PHY TX instance that sets Edge Clock Mode as Internal, provides the synchronizer 
and divider, and serves as the primary clock source.
