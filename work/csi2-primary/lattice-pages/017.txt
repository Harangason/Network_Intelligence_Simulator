2.2.2. MIPI CSI/DSI Receiver Clocking Overview 
Input clocks shown in Figure 2.5 and Figure 2.6 are typically generated using an external PLL while the output clock, 
byte_clk_o, is generated by an FPGA clock divider element. For more details of each clock, refer to the Signal 
Description section. 
Table 2.2. MIPI CSI/DSI Receiver Operating Frequency Details and Requirements 
Clock Operating Frequency Details and Requirements 
ref_clk_i The operating frequency of this clock can be set using the Reference Clock Frequency (MHz) 
attribute. Supported values are 60 MHz and up to 200 MHz, depending on the device 
configuration. 
byte_clk_o The frequency of this clock can be calculated as: Actual Byte Clock Frequency (MHz) = Line Rate 
Per Lane (Mbps)/PHY Data Width. 
fr_clk_i The operating frequency of this clock can be set to greater than or equal to Actual Byte Clock 
Frequency (MHz), with a minimum value of 60 MHz. 
axis_vid_clk_i The operating frequency must be computed as follows, with minimum of Actual Byte Clock 
Frequency (MHz): 
axis_vid_clk_iMHz_TEMP = ((Number of D-PHY Lanes × PHY Data Width) / (Number of Pixel per Clock 
(PPC) × BPP1)) × Actual Byte Clock Frequency (MHz) 
 
If axis_vid_clk_iMHz_TEMP < Actual Byte Clock Frequency (MHz): 
• axis_vid_clk_iMHz ≥ Actual Byte Clock Frequency (MHz) 
Else: 
• axis_vid_clk_iMHz ≥ axis_vid_clk_iMHz_TEMP 
 
Example 1: 
Line Rate Per Lane (Mbps) = 1,500 
PHY Data Width = 8 
Number of D-PHY Lanes = 4 
Number of Pixel per Clock (PPC) = 4 
Enable RGB888 Color Format = checked (BPP = 24) 
Actual Byte Clock Frequency (MHz) = 187.5 MHz 
 
axis_vid_clk_iMHz_TEMP = ((4 × 8) / (4 × 24)) × 187.5 = 62.5 MHz 
As 62.5 MHz < 187.5 MHz, axis_vid_clk_iMHz ≥ 187.5 MHz
