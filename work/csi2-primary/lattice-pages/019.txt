2.4.1. Unified Video Streaming Interface (UVSI) 
The UVSI transfers video data in the pixel domain and complies with the AXI4 -Stream protocol. For the complete list of 
interface signals, refer to the Signal Description section. 
In UVSI, the first transmission of every frame is always the frame boundary, indicated by the assertion of the Start of 
Frame (SOF) signal. This transition marks the beginning of the valid video-frame data. The data flow strictly follows the 
AXI4-Stream handshaking requirements, where the source must assert TVALID only when valid data is available, and 
the sink must assert TREADY only when the sink is ready to accept data. A data beat is transferred only when both 
TVALID and TREADY are high, ensuring proper flow control and preventing data loss or corruption.
