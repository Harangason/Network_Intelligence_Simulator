2.12.3. MIPI CSI/DSI Transmitter Resolution Reconfiguration 
In MBSI mode, you only generate the appropriate frame packets at the MBSI interface. To reconfigure the resolution in 
the UVSI mode, follow these steps: 
1. After sending the whole frame packet, wait for 2 ms to allow packet processing to complete. Skip Step 1 if you need 
to change the resolution after power up and before sending any packets.  
2. Read PHY_CONFIG_REG 0x020[0] to check if CFG_READY is 1 to proceed to the next step. 
3. Write the new number of vertical lines per active frame into CONFIG_REG2 0x244[31:16]. When the Blanking 
Period Enable (BP_EN) option is enabled, NUM_LINE_V_BLANKING, H_BLANKING_BYTES_TH (CONFIG_REG1), and 
NUM_BYTES_ACTIVE_H (CONFIG_REG2) must be configured accordingly. 
4. Send a new frame packet with the new resolution.
