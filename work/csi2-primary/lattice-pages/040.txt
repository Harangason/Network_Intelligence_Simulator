Miscellaneous 
Line Buffer Depth depthN, depthN×2, 
depthN×4 
Defines the depth of the line-buffer FIFO used in the Pixel-to-Byte 
(P2B) block for TX. The FIFO has a fixed width of 256 bits. The 
required depth is determined by the number of active pixels per line 
and the selected bits-per-component. 
The minimum depth (depthN) is computed as the smallest 
power-of-two FIFO depth that can hold one full video line, using ceil() 
to ensure the FIFO is never undersized. You may select depthN×2 or 
depthN×4 to increase buffering margin when horizontal blanking is 
short or absent. This attribute is available only when PHY Direction is 
set to TX. 
FIFODEPTH = Ceil((Hactive × BPC)/256)
