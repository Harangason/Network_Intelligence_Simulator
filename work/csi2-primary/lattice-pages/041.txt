PHY Direction == TX:  
Specifies the depth of the internal byte data buffer. The default 
minimum setting is depthN. 
 
If TDATA_WIDTH = 32 
GUI Options: 512, 1024, 2048, 4096, 8192, 16384 
If TDATA_WIDTH = 64 
GUI Options: 512, 1024, 2048, 4096, 8192 
 
For both TDATA_WIDTH = 32 and TDATA_WIDTH = 64, the byte 
buffer FIFO stores the complete MIPI packet, including the packet 
header, payload, and CRC bytes, along with the required sideband 
information. Therefore, the maximum supported payload size is 
equal to the total packet size in bytes minus 8 bytes.
