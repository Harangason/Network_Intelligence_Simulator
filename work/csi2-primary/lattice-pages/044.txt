4. Signal Description 
This section describes the MIPI CSI/DSI IP ports. 
4.1. MIPI CSI/DSI TX Signal Description 
4.1.1. Clock Interface 
Table 4.1. Clock and Reset Ports 
Port Type Description 
ref_clk_i Input Clock input for PHY fabric-based implementation. This clock drives all PHY fabric related 
logic and follows the frequency set in the Reference Clock Frequency (MHz) attribute. 
Available if PHY Mode == Soft D-PHY and Edge Clock Mode == Internal or when PHY Mode 
== Hard D-PHY. 
ref_rst_n_i Input Asynchronous active-low reset input. This is synchronized internally with ref_clk_i clock. 
This resets all logic and blocks in the ref_clk_i domain. 
Available if PHY Mode == Soft D-PHY and Edge Clock Mode == Internal or when PHY Mode 
== Hard D-PHY. 
pll_clkop_i Input External PLL clock input operating at the D-PHY high-speed clock frequency. This is the 0-
degree phase PLL output used as the primary reference for generating the HS clock lane. 
Available if PHY Mode == Soft D-PHY and Edge Clock Mode == Internal. 
pll_clkos_i Input External PLL clock input that is 90 degrees phase-shifted from pll_clkop_i. Provides the 
quadrature HS clock required for DDR edge alignment in the D-PHY clock lane. 
Available if PHY Mode == Soft D-PHY. 
axis_vid_clk_i Input When Unified Video Streaming Interface (UVSI) is checked: Clock input to the pixel-to-
byte conversion logic and line buffer. The clock frequency is recommended to be 
determined by the selected video parameters such as resolution, frame rate, and pixel 
format. The IP includes a configurable line buffer that operates using a store-and-forward 
mechanism. 
When MIPI Byte Streaming Interface (MBSI) is checked: Clock input to the byte buffer 
write operation to store incoming MIPI packets.  
axis_vid_rst_n_i Input Active-low AXI4-Stream video reset input for the Pixel-to-Byte converter. This is 
synchronized internally with axis_vid_clk_i. Resets logic in pixel domain. 
s_axi_aclk_i Input The AXI4-Lite interface clock that drives the control and status register (CSR) logic and 
operates at a maximum frequency of 60 MHz. 
s_axi_aresetn_i Input Active-low AXI4-Lite reset input for control and status registers. 
Edge Clock Sharing 
byte_clk_i Input Byte clock input. 
Connects to byte_clk_o of source instance with Edge Clock Mode == Internal. 
Available if Edge Clock Mode == External3. 
eclk_syncclk_i Input Drives the Edge Clock pin of DDR modules of data path. 
Connects to eclk_syncclk_o of source instance with Edge Clock Mode == Internal. 
Available if Edge Clock Mode == External3. 
eclk_reset_i Input Drives the reset port of DDR modules. 
Connects to eclk_reset_o of source instance with Edge Clock Mode == Internal. 
Available if Edge Clock Mode == External3. 
eclk_ready_i Input Indicates the clock synchronization status to sink instance.  
Connects to eclk_ready_o of source instance with Edge Clock Mode == Internal. 
Available if Edge Clock Mode == External3. 
byte_clk_o Output Byte clock output. Byte Clock is generated by gearing down pll_clkop_i and operates as a 
divided version of the PLL output clock. 
Connects to byte_clk_i of sink instance with Edge Clock Mode == External. 
Available if Edge Clock Mode == Internal3 or when PHY Mode == Hard D-PHY. 
eclk_syncclk_o Output Drives the Edge Clock pin of DDR modules of data path. 
Connects to eclk_syncclk_i of sink instance with Edge Clock Mode == External.
