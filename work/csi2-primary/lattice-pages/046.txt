4.1.5. Miscellaneous  
Table 4.5. Miscellaneous Ports 
Port Type Description 
tinit_done_o Output Indicates completion of the D-PHY LP-11 initialization period. When Enable 
tINIT Counter is checked, this signal asserts after (tINIT counter value – 1) 
byte-clock cycles, representing the programmed LP-11 duration. When the 
Enable tINIT Counter is unchecked, the signal asserts automatically when the 
internal soft PHY has entered and stabilized in LP-11 state, indicating that the 
link is ready for HS entry. 
horizontal_blanking_cnt_en_o Output Indicates that the additional horizontal line blanking is inserted in the LP-11 
state between HS burst of consecutive long packets (Line Start and Line End is 
disabled) or between HS burst of the current Line End to the next Line Start of 
short packets (Line Start and Line End is enabled). The duration of the 
assertion indicates the additional blanking duration period inserted in the LP-
11 state. This signal is active only when the Number of Horizontal Blanking 
Bytes in Byte Clock Domain is set to a non-zero value. 
This port is available only when Blanking Enable is set. 
vertical_blanking_cnt_en_o Output Indicates that the additional vertical frame blanking is inserted in the LP-11 
state between HS burst of the current Frame End to the next Frame Start of 
short packets. The duration of the assertion indicates the additional blanking 
duration period inserted in the LP-11 state. This signal is active only when the 
Number of Vertical Blanking Lines Per Frame is set to a non-zero value. 
This port is available only when Blanking Enable is set.
