4.2.1. Clock Interface 
Table 4.7. Clock and Reset Ports1 
Port Type Description 
ref_clk_i Input This is the clock input for soft PHY fabric-based implementation, and Hard D-
PHY automatically generated power-up sequence and escape clock. 
Available if PHY Mode == Soft D-PHY or when PHY Mode == Hard D-PHY. 
ref_rst_n_i Input Asynchronous active-low reset input. This is synchronized internally with 
ref_clk_i clock. This resets all logic and blocks in the ref_clk_i domain. 
Available if PHY Mode == Soft D-PHY or when PHY Mode == Hard D-PHY. 
byte_clk_o Output Byte clock output recovered from the MIPI data stream. Represents the rate 
at which payload bytes are extracted from received packets. This is active only 
when the clock lane is in high-speed mode. Frequency is displayed as Actual 
Byte Clock Frequency (MHz). 
fr_clk_i Input Free-running clock. Determines the rate at which received MIPI packets are 
processed. Drives the logic that detects the low power to high-speed 
transition of clock and data lanes. 
fr_rst_n_i Input Asynchronous active-low reset input. This is synchronized internally with 
fr_clk_i clock. Resets all logic and blocks in the fr_clk_i domain. 
axis_vid_clk_i Input AXI4-Stream video clock input for the Byte-to-Pixel converter output 
interface. Drives the pixel processing pipeline including format conversion, 
pixel packing, and AXI4-Stream protocol generation. 
axis_vid_rst_n_i Input Active-low AXI4-Stream video reset input for the Byte-to-Pixel converter. This 
is synchronized internally with axis_vid_clk_i. Resets logic in pixel domain. 
s_axi_aclk_i Input AXI4-Lite interface clock input.  
s_axi_aresetn_i Input Active-low AXI4-Lite interface reset input.  
Note: 
1. The operating clock frequency and requirements information are available in the MIPI CSI/DSI Receiver Clocking Overview 
section.
