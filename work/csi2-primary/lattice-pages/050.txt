5. Register Description 
The control and status register (CSR) interface is implemented using an AXI4-Lite subordinate interface and is used to 
configure, control, and monitor the IP. 
5.1. MIPI CSI/DSI Transmitter Register Description 
Table 5.1. Summary of MIPI CSI/DSI Transmitter Registers

Register Name Description

0x220 CONFIG_REG0 Configuration Register 0 
0x240 CONFIG_REG1 Configuration Register 1
