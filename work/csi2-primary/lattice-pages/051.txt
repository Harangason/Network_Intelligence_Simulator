5.1.5. CONFIG_REG0 (0x220) 
Table 5.6. CONFIG_REG0 (0x220) Register 
Field Name Description Access Default 
[14:0] T_SKEW_INITIAL Period of initial skew calibration in word clock cycle. 
This register is applicable only when PHY Mode == 
Hard D-PHY. 
 
Example: 
PHY Mode = Hard D-PHY 
Line Rate Per Lane = 2500.0 Mbps 
PHY Data Width = 16 
T_SKEW_INITIAL = 2049 (0x0801) 
Byte Clock Period = PHY Data Width / Line Rate Per 
Lane × 1000 = 16 / 2500.0 × 1000 = 6.4 ns 
 
Programming T_SKEW_INITIAL with a value of 2049 
(0x0801) sets a skew calibration period of 2049 × 6.4 
ns. When triggered via the CAL_INITIAL_TRIGGER_EN 
register bit, this results in a calibration time of 
approximately 13113.6 ns across the serial links.
