6.1.1. Generated Files and File Structure 
The generated MIPI CSI/DSI module package includes the closed-box (<Component name>_bb.sv) and instance 
templates (<Component name>_tmpl.sv/vhd) that can be used to instantiate the core in a top-level design. An example 
RTL top­level reference source file (<Component name>.sv) that can be used as an instantiation template for the 
module is also provided. You may also use this example as the starting template for your top-level design. The 
generated files are listed in Table 6.1. 
Table 6.1. Generated File List 
Attribute Description 
<Component name>.ipx Contains the information on the files associated with the generated IP. 
<Component name>.cfg Contains the parameter values used in IP configuration. 
component.xml Contains the ipxact: component information of the IP. 
design.xml Documents the configuration parameters of the IP in the IP-XACT 2014 format. 
eval/constraint.pdc Provides reference timing constraints and virtual I/O assignments for IP evaluation in the 
Lattice Radiant software. 
eval/dut_inst.v Provides a port connection template for instantiating the module. 
eval/dut_params.v Provides the parameter definitions used to configure the module. 
eval/eval_top.sv Provides an example evaluation top-level file for synthesis that instantiates the module. 
rtl/<Component name>.sv Provides an example RTL top file that instantiates the module.
