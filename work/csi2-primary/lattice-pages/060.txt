Notes: 
• You need to provide proper timing and physical design constraints to ensure that your design meets the desired 
performance goals for the FPGA. 
• The constraint files have been verified during IP evaluation with the evaluation wrapper instantiated directly in the 
top-level module. 
• During synthesis, you can ignore clock related warnings as the evaluation IP does not include clock -related 
constraints at pre-synthesis level. 
• During post-synthesis, there may be warnings related to dropped constraints. As the IP supports many 
configurations and parameter combinations, some default constraints may not be applicable to the selected 
configuration.  
• In transmitter mode, if Edge Clock Mode is set to Internal, you may encounter a Place and Route error as the edge 
clock synchronizer clock (eclk_syncclk_o) is illegally mapped to the FPGA I/O. This clock is intended to be 
connected to a DDR primitive or just left unconnected if unused. You may include the eval_top.sv as a top-level 
wrapper during IP synthesis stage to achieve a full compilation stage. The eval_top.sv must be set to Include for – 
Synthesis only and avoid using the file as top-level wrapper for simulation stage. 
For more information on timing constraints, refer to the Lattice Radiant Timing Constraints Methodology (FPGA-AN-
02059).
