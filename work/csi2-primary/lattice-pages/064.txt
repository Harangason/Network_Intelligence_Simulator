7. Example Design 
The MIPI CSI/DSI example design demonstrates the MIPI video streaming receiving and transmitting from the MIPI CSI 
IP in the FPGA with external MIPI CSI components.  
This example design supports the following modes which are selectable using the DIP switch on the FPGA board:  
• RX to TX retransmit mode: The external camera sensor (MIPI CSI source) transmitted to the MIPI RX IP (MIPI CSI 
sink), retransmitted to the MIPI TX IP (MIPI CSI source) before transmitting to the external Raspberry Pi 5 board 
(MIPI CSI sink).  
• Pattern subsystem to TX mode: The internal pattern generator in the FPGA transmitted to the MIPI TX IP (MIPI CSI 
source) before transmitting to the external Raspberry Pi 5 board (MIPI CSI sink). 
Refer to the Setting Up the CertusPro-NX PCIe Vision Board section for details on the DIP switch settings. 
The MIPI CSI/DSI example design validates the MIPI CSI/DSI IP in CertusPro-NX devices using the following hardware:  
• CertusPro-NX PCIe Vision Board 
• Sony® IMX258 camera sensor 
• Raspberry Pi 5 board
