Sensor LMMI Driver 
The sensor LMMI driver configures the I2C Controller IP to initiate the basic I2C transactions to initialize the sensor 
camera. In this example design, the sensor LMMI driver configures the I2C Controller IP in sequence via the predefined 
static ROM configuration setting. 
I2C APB Driver 
The I2C APB driver configures the I2C Target IP with the corresponding data (for example, CHIP_ID) in response to the 
I2C controller on read transaction. In this example design, the I2C APB driver configures the CHIP_ID value for the ACK 
response to the Raspberry Pi 5 OS during driver probing.

RISC-V MC IP 
The RISC-V MC CPU IP has advanced high-performance bus (AHB)-Lite based instruction and data ports. The instruction 
port is connected to the system memory that contains the system application for the central processing unit (CPU) to 
boot up when the FPGA is programmed. In this example design, the data port is connected to the system memory and 
other peripherals for control and status read. The CPU also receives user input commands from the demo GUI 
application via the universal asynchronous receiver/transmitter (UART) serial communication.
