7.7.1. RISC-V Bare Metal Program 
The bare metal program is built on-top of the RISC-V MC CPU Hello World template that is generated using the Lattice 
Propel software. 
Table 7.4. Main API 
API Function Description API Function Description 
int main (void) When you power cycle the FPGA device or assert the system reset, the main function 
initializes all peripherals in the RISC-V subsystem. After that, this function waits for the 
user input commands received from the demo GUI via UART communication. 
static int bsp_init(void) Called within the main function which is responsible for initializing and configuring the
