7.9. Example Design Hardware Setup 
This section describes how to set up and run the example design using the following Lattice software:  
• Lattice Radiant software 
• Lattice Propel Builder software 
7.9.1. Locating the Example Design Files 
To locate the example design files, follow these steps: 
1. Generate the MIPI CSI IP through the Lattice Radiant software. The example design is in the <Generated IP 
component directory>/eval folder. 
2. Unzip the .zip file in your generated IP component directory.  
7.9.2. Opening the Lattice Propel Builder Project 
The RISC-V subsystem is constructed using the Lattice Propel Builder software, follow these steps to open the RISC-V 
subsystem in the Lattice Propel Builder software: 
1. Invoke the Lattice Propel Builder software. 
2. Click File > Open Design and from the project database, open the Lattice Propel Builder Sbx file (.sbx) from the 
<Generated IP component directory>/eval/mipi_vision_interopt/common/riscv_subsystem folder.  
3. Navigate to Schematic or the Address tab to view the connections of the RISC-V subsystem and the base address 
for the corresponding target and controller.
