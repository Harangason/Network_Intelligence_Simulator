7.9.3. Regenerating the IP and Recompiling the Lattice Radiant Software Project 
To regenerate the IP and recompile the Lattice Radiant software project, follow these steps:  
1. Invoke the Lattice Radiant software. 
2. Click File > Open Project and from the project database, open the Lattice Radiant software project file (.rdf) from 
the <Generated IP component directory>/eval/mipi_vision_interopt/hardware folder. 
3. From the left panel, double-click mipi_tx_ip.ipx and mipi_rx_ip.ipx to regenerate the MIPI CSI IP from the current 
Lattice Radiant software project. 
Note: All other IP components other than the MIPI CSI IP are pre-generated, you are advised not to regenerate these IP 
components. 
4. Click Run all to initiate full compilation. 
5. The bitstream file is generated in this path:  
<Generated IP component directory>/eval/mipi_vision_interopt/hardware/impl_1/mipi_interopt_ed_impl_1.bit 
Note:  
The bitstream file is pre-generated in the <unzipped example design directory>/bitstream folder, thus, compilation steps 
are optional. 
If you recompile or regenerate IP components, ensure the Read-only attribute is unticked from properties of <unzipped 
example design directory> as follows: 
1. Right-click on the <unzipped example design directory>. 
2. Select Properties. 
3. Locate the Read-only option under Attributes type. 
4. Untick the Read-only option if it is enabled. 
5. Click OK.
