7.9.4.1. Setting Up the CertusPro-NX PCIe Vision Board 
To set up the CertusPro-NX PCIe Vision Board, follow these steps: 
1. Connect the 12 V power adaptor to J23. 
2. Connect the mini-USB Type A cable from the PC to J17. 
3. Connect the IMX258 sensor camera to CN2. 
4. Connect the 22-pin FFC/FPC flexible flat cable to J42. 
5. Connect the jumpers as follows: 
a. Pin 2 and 3 at J70 
b. Pin 2 and 3 at J78 
c. Pin 1 and 3 at J80 
d. Pin 1 and 2 at J13 
e. Pin 1 and 2 at J14 
f. Pin 1 and 2 at J47 
g. Pin 1 and 2 at J46 
6. Configure the SW1 DIP switch according to the table below.

7.9.4.2. Setting Up the Raspberry Pi 5 Board 
To set up the Raspberry Pi 5 board, follow these steps: 
1. Connect the power adaptor to J1. 
2. Connect the HDMI cable from J13 to the monitor. 
3. Connect the FFC/FPC flexible flat cable to CAM/DISP0. 
Notes:  
• You must program the bitstream into the FPGA device before switching on the Raspberry Pi 5 board. 
• You must perform system reset with the on-board push button or reprogram the FPGA board first if you want to 
restart the Raspberry Pi 5 board. 
For first time setup of the Raspberry Pi 5 OS, refer to the Setting Up the MIPI CSI Display in the Raspberry Pi 5 OS 
section. 
7.9.5. Running the Hardware 
To run the example design, follow these steps: 
1. Switch off the Raspberry Pi 5 board. 
2. Set the SW1 DIP switch according to the default settings in Table 7.6. 
3. Open the Lattice Radiant software project. Refer to step 2 in the Regenerating the IP and Recompiling the Lattice 
Radiant Software Project section. 
4. In the Lattice Radiant software, Click Tools > Programmer to invoke the Lattice Radiant Programmer.
