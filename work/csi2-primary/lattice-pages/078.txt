To configure and run the video pattern in the Pattern Subsystem to TX mode, follow these steps: 
1. Ensure switch 4 from the Setting Up the CertusPro-NX PCIe Vision Board section is set to Pattern Subsystem to TX 
mode. 
2. Terminate the existing preview session in the Raspberry Pi 5 OS. The session is invoked from step 9 in the Running 
the Hardware section. 
3. Under Video Data Control, select the Pattern Mode and Color Filter Array (CFA) settings. 
4. Click Configure to update the settings. 
5. Click Start to enable video pattern transmission. 
6. Invoke a new preview session in the Raspberry Pi 5 OS per step 9 in the Running the Hardware section. 
7. Click Stop to disable video pattern transmission. 
8. Repeat step 2 to step 7 if you switch to Pattern Mode or Color Filter Array (CFA).
