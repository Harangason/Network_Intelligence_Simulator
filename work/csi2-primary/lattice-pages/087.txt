For Vertical Frame Blanking Insertion Only 
With the horizontal line blanking period at a minimal value determined by the video FSM, adjust the LP-11 state 
between consecutive Frame End the next Frame Start short packet to increase or decrease the Frame Period.  In this 
case, the value configured in Number of Horizontal Active Bytes in Byte Clock Domain is Actual Active Bytes plus 
additional dummy bytes which is used by TX to insert only vertical frame blanking line duration. The  Number of 
Horizontal Blanking Bytes in Byte Clock Domain parameter is set to zero. This does not impact the actual pixel data 
packet received by TX from the user interface.
