Vertical Frame Blanking Duration = 16666 µs – (1080 x 14.1187 µs) 
    = 1417.804 µs 
 
Number of Vertical Blanking Lines Per Frame = Vertical Frame Blanking Duration/(Number of Horizontal Active Bytes in 
Byte Clock Domain x Byte Clock Period) 
 = 1417.804 µs / (1200 x 8.77193 ns) 
 = ~134 lines 
 
To determine the actual vertical frame blanking duration required, configure the values as follows: 
• Number of Vertical Blanking Lines Per Frame (IP Wizard GUI) or NUM_LINE_V_BLANKING field (CONFIG_REG1)—
Set to the calculated value in the example    
• Number of Horizontal Active Bytes in Byte Clock Domain (IP Wizard GUI) or NUM_BYTES_ACTIVE_H field 
(CONFIG_REG2)—Set to 1200 
• Number of Horizontal Blanking Bytes in Byte Clock Domain (IP Wizard GUI) or H_BLANKING_BYTES_TH field 
(CONFIG_REG1)—Set to 0 
With the initial configuration settings in the example, trigger the IP simulation and analyze the vertical frame blanking 
duration in the LP-11 state between the Frame End HS burst and next Frame Start HS burst.
