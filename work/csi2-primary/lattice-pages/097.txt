Troubleshooting the Raspberry Pi 5 Camera Software Preview Issue 
The following figure shows the example error message you may see in the Raspberry Pi 5 OS when running the preview 
command. 
  
Figure B.2. Timeout Error in the Raspberry Pi 5 OS  
The error occurs because of no active data transmission detected in the Raspberry Pi 5 camera software from the MIPI 
connector on the Raspberry Pi 5 board.  
To resolve this issue, perform the following steps: 
1. Terminate the current preview session in Raspberry Pi 5 OS. 
2. Switch off both the Raspberry Pi 5 board and the CertusPro-NX PCIe Vision Board.  
3. Ensure the hardware setup is correct as described in the Hardware Board Setup section. 
4. Ensure the correct 22-pin FFC/FPC flexible flat cable is used for the connection between the Raspberry Pi 5 board 
and the CertusPro-NX PCIe Vision Board. 
5. Follow the Hardware Board Setup section to rerun the hardware. 
6. Verify both Pattern Subsystem to TX mode and RX to TX Retransmit mode to identify whether the issue occurs in 
both modes or in only one mode.
