The difference between a traditional Modbus Protocol Data Unit ( PDU) and the Modbus/TCP 95

In 1996 the Modbus/TCP protocol, was registered with IANA 99 
(Internet Assigned Number Authority) and assigned the 100 
system port number 502. In the course of this registration 101 
process with IANA the Modbus/TCP protocol came to be 102 
called the mbap protocol because of the mbap header in the 103 
Modbus/TCP ADU. This name,  the mbap protocol, persisted 104 
and is still use d for the port 502 registration with the IANA  as 105 
mbap/TCP  106

The Modbus/TCP Security protocol is a secur ity focused  108 
variant of the Mobdbus/TCP protocol  utilizing Transport 109 
Layer Security (TLS) . IANA has assigned the Modbus/TCP 110 
Security protocol the system port number 802. Modbus.org 111 
has registered the name Modbus Security Application 112 
Protocol to the protocol registered at port 802  with IANA as 113 
mbap/TLS/TCP  114 
 115 
The selection of TLS as the secure transport protocols is the result of analyzing representative 116 
data flows from industry domains in the context of [62443- 3-3] and [62443-4-2]. 117
