The development of mbaps and its deployment in a device were guided by a set of principles 198 
including:  199 
• R-01: The TLS Protocol v1.2 as defined in [RFC5246] or newer MUST be used as the 200 
secure transport protocol for an mbaps Device. 201 
• R-02: Secure communications to an mbaps Device MUST use Mutual client/server 202 
authentication as provided by the TLS Handshake Protocol.   203 
• R-03: x.509v3 Certificates as defined in [RFC5280] MUST be used as mbaps device 204 
credentials for Identity/Authentication by the TLS protocol. 205 
• R-04: If the Authorization function is enforced it MUST use the role transferred via 206 
x.509v3 certificate extensions. 207 
• R-05: There MUST be no change to the mbap protocol as a consequence of it being 208 
encapsulated by the secure transport.  209

8 Protocol Specification 216 
8.1 General 217 
 218 
The communication of an mbap ADU is secured using the Transport Layer Security protocol, 219 
TLS, defined in [RFC5246]. Figure 3 mbap ADU Encapsulated in TLS illustrates how an mbap 220 
ADU is transmitted via the TLS Application Protocol.  221 
 222 
TLS provides Transport Layer Security between two end points. To do this, the TLS end points 223 
execute the TLS Handshake protocol to negotiate security parameters and to create a TLS 224 
session.  225 
 226 
8.2 TLS Handshake 227 
 228 
For two mbaps end devices to communicate securely using TLS, a security context between the 229 
end points of the TLS connection must be established. The TLS Handshake protocol  establishes 230 
the secure context, i.e. the TLS session. The TLS session has a session identifier and the 231 
security context is described by a set of security parameters as defined in [RFC5246] section A.6.  232 
 233 
Mutual Authentication requires that each end point will send its domain certificate  chain to the 234 
remote end point. Upon receipt of a certificate chain from the remote peer, the TLS end point will 235 
verify the each certificate signature using the next CA certificate in the chain until it can verify the 236 
root of the chain. 237
