10.2.3 TLS Authentication 447 
Authentication against trust anchors may be done using self signed device certificates. It is 448 
recommended to use certificates signed by a Certificate Authority for authentication.  449 
 450 
Session resumption using session tickets or resuming session IDs should be supported to reduce 451 
the handshake time of a connection.Session resumption using session IDs is preferred. In 452 
session resumption it is the responsibility of the server to cache and maintain session information 453 
for later use. It is more well supported and places less demand on clients to manage session 454 
information with their peer.  455 
 456 
Session tickets place the burden of session information on the client. This information is 457 
encrypted by the server and transmitted to the client. On new session, this information is 458 
transmitted back to the server and used to re-establish a connection. Less server resources are 459 
needed to accomplish this but network resources are wasted and due to the transmission of 460 
information it takes longer to re-establish a connection. 461
