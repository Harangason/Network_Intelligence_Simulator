10.2.4 TLS Encryption 481 
 482 
R-48: If an mbaps Device is to be used in a scenario where encryption is required, then a cipher 483 
suite with the required encryption indicator MUST be chosen from the list at IANA’s TLS Cipher 484 
Suite Registry in the [TLS-PARAMS]. 485 
 486 
R-49: If an mbaps Device is to be used in a scenario where encryption is not required, then a 487 
cipher suite with a NULL bulk encryption indicator MUST be chosen from the list at IANA’s TLS 488 
Cipher Suite Registry in the [TLS-PARAMS]. 489
