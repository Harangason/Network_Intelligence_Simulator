2 Pinout
Input pins must not be left floating; therefore, they must be driven, have pull-ups or pull-downs, or be tied
directly to one of the power or ground pins.
Digital pins that can be configured as outputs (e.g. D I/O, DOUT, DI/OD) are high impedance during power-
up/reset. Immediately following power-up/reset:
/square6 pins with more than one configuration option are as follows:
/square6 Pin 29 - DSCL functionality (DI/OD) - assumes TMS high
/square6 Pin 30 - DSDA functionality (DI/OD) - assumes TMS high
/square6 Pin 32 - MLBSIG functionality (DI/O) - default can be changed via the INIC Configuration String
/square6 Pin 33 - MLBDAT functionality (DI/O) - default can be changed via the INIC Configuration String
/square6 Pin 34 - High impedance until configured
/square6 Pin 35 - High impedance until configured
/square6 Pin 41 - ERR functionality (DOUT) - unless held low at the rising edge of reset
/square6 Pin 42 - DINT functionality (DOUTD)
/square6 Pin 43 - INT functionality (DIN) - assumes ERR/BOOT high
/square6 output pins with a disable option remain in the high impedance state, unless specifically enabled by 
software (e.g. RMCK, SYNC, MLBCLK), and
/square6 all other pin types are as shown in Table 2-1.
