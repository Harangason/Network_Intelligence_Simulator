When the MediaLB Port is configured for MediaLB 3-pin mode, two serial interfaces are available through
the Streaming Port. The following input/output configurations are available in Partial Streaming Mode:
/square6 InOut Option - interface supports one serial input ( SR0) and one serial output ( SX0)
/square6 DualIn Option - interface supports two serial inputs ( SR0 and SR1)
/square6 DualOut Option - interface supports two serial outputs ( SX0 and SX1)
