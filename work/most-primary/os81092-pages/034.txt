8.4 MediaLB Debug Header
A standard MediaLB Debug Header is defined to allow various MediaLB analysis and debug tools to connect directly
into the application. This header is used for monitoring MediaLB in either the 3-pin or 5-pin mode, and should be placed
as close as possible to the MediaLB interface to prevent unnecessary extension of MediaLB signal traces.
The pinout of the MediaLB Debug Header, as shown in Figure 8-7, is compatible with MediaLB Active Pods for MediaLB
3-pin and 5-pin modes. Active Pods are used with various MediaLB analysis and debug tools (see the MediaLB Monitor
Adapter User’s Manual [6] and MediaLB Analyzer User’s Manual [7]). This header should be a 10-pin, 2 mm male con-
nector, such as Molex 87332-1020 (shrouded) or Samtec TMM-105-06-T-D-SM (not shrouded).
