12.0 GENERAL PURPOSE INPU T/OUTPUT (GPIO) PORT
The OS81092 allows certain pins to be reprogrammed from their default function to support general purpose input/out-
put (GPIO) functionality. Each GPn pin and its default function is listed in Table 12-1. The user may enable the GPIO
Port using the INIC Configuration String. See the OS81092 INIC API User’s Manual [2] for more information.
12.1 GPIO Classes
GPIO pins are highly configurable which provides the user with the flexibility to support various applications. The follow-
ing GPIO pin modes are available:
• Output (Push-Pull) - High Level or Low Level
• Output (Open-Drain) - default state Hi-Z or default state driven low. Trigger: Rising Edge, Falling Edge, High Level, 
Low Level.
• Input - Trigger: Rising Edge, Falling Edge, High Level, Low Level.
• Sticky Input  - Trigger: Rising Edge, Falling Edge
• Debounced Input - Trigger: Rising Edge, Falling Edge, High Level, Low Level
At OS81092 power-up/reset, all GPIO pins are high-impedance inputs, except GP7, which is an Open-Drain Output con-
figured to be Hi-Z by default. During GPIO initialization, the user specifies the pin configuration for each GPIO pin that
is used and configures any other relevant details, such as debounce settings. Refer to Chapter 15.0 “Electrical Charac-
teristics” for GPIO details such as voltage levels and timing. Fu rther details for each GPIO mode are included in the
following subsections and the OS81092 INIC API User’s Manual [2].
Note: The GPIO Port is only available when using OS81092 Revision C1D or later.
Refer to Appendix C: “Feature Matrix” for more information.
