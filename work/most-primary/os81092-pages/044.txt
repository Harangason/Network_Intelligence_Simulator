12.2 GPIO Triggers
12.2.1 LEVEL-SENSITIVE TRIGGERS
A Level-Sensitive Trigger is a trigger that monitors the state of the pin and generates an event notification when either
high-level or low-level logic is detected. The event notification remains valid as long as the signal stays active (e.g. high
or low, depending on configuration).
The Level-Sensitive Trigger is appropriate for signals where active levels are maintained until serviced. An advantage
to this trigger mode is that subsequent event triggers are signaled once t he controlling device re-enables event notifi-
cations, provided the active level has been maintained. This behavior is desirable in the following application scenarios:
• the peripheral attached to the OS81092 GPIO pin does not de-assert its hardware interrupt between events
• interrupt lines from multiple hardware peripherals are ganged together (e.g. using open-drain logic) onto a single 
OS81092 GPIO pin
A limitation of the Level-Sensitive Trigger is that a higher-level application must manually clear events in order to re-
enable the reporting of subsequent event notifications.
12.2.2 EDGE-SENSITIVE TRIGGERS
An Edge-Sensitive Trigger generates an event notification when signal transitions are detected and are appropriate for
detecting simple toggle events on an input signal. The advan tage to using this GPIO mode is that subsequent signal
transitions are immediately reported to the controlling application.
