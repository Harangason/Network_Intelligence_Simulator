16.6.1 EHC VIA CONTROL PORT
The INIC Configuration String data can be written into OTP memory by the EHC via the OS81092 Control Port. To sup-
port this feature, the EHC must be connected to the INIC Control Port (SDA, SCL, and INT) and be capable of controlling
the ERR/BOOT and RST pins. The required connections are shown in Figure 16-2.
