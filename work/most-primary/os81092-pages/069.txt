16.6.2 INIC EXPLORER VIA JTAG PORT
The OS81092 JTAG Port can be converted into a configuration interface for use with the Microchip INIC Explorer Inter-
face Box [4] tool. INIC Explorer requires that the application PCB provide a standard 14-pin (2x7) 2 mm header (such
as Molex 87332-1420 or equivalent). The interface between the INIC Explorer tool and the OS81092 is also referred to
as the Customer Configuration Interface.
In addition to writing INIC Configuration String data into OTP memory, the INIC Explorer platform provides debugging
capabilities by allowing users to access INIC (via PC software) for:
• Exploring internal INIC properties and states while it is operating in the target platform,
• Viewing internal INIC states and routing configurations graphically, and
• Creating an INIC data memory snapshot as a file dump.
Figure 16-3 illustrates the necessary connections between t he OS81092 and the configuration/debug header that
accommodates INIC Explorer. To allow the header to drive the ERR/BOOT and RST pins during configuration, the pull-
up resistors on these lines should be greater than 10 k . If the ERR/BOOT and RST lines are also connected to the
EHC (as described in Section 16.6.1 “EHC via Control Port”), the EHC must use open-drain logic or set its outputs as
high-impedance when the INIC Explorer connects to the OS81092 via the configuration/debug header.
