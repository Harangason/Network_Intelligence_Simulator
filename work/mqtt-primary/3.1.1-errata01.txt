standard and its related works.
2.1 Remaining length
range check.
The pseudocode in section 2.2.3 of the MQTT V3.1.1
specification [MQTT311], does not correctly detect a fixed header remaining
length greater than 2,097,151 bytes. To correct the pseudocode move the range
check so that it precedes the multiplier update.
Remove:
multiplier = 1
value = 0
do
encodedByte = 'next byte from stream'
value += (encodedByte AND 127) * multiplier
multiplier *= 128
if (multiplier > 128*128*128)
throw Error(Malformed Remaining Length)
while ((encodedByte AND 128) != 0)
Add:
multiplier = 1
value = 0
do
encodedByte = 'next byte from stream'
value += (encodedByte AND 127) * multiplier
if (multiplier > 128*128*128)
throw Error(Malformed Remaining Length)
multiplier *= 128
while ((encodedByte AND 128) != 0)
