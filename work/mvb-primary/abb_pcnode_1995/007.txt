Frame format The frame format is optimised for short and frequent data items:
 The master frame has a fixed size of 33 bits (9 + 16 + 8).
 Slave frames comprise a 9 bit frame delimiter, and a data por-
tion which length depends on the function code in the master 
frame, followed by an 8-bit check sequence per 64 bit data. 
Longer slave frames use two or four 64+8-bit data-portions.
