IPTCom
IPTCom is an Ethernet network on board a train, based on the Internet-Protocol (IP). The DHCP, ARP, TCP and
UDP protocols which are used are all based on the Internet-Protocol (IP). IPTCom makes use of these protocol
layers in order to implement its own protocol. 
Terminal connection:
· IPTCom is a 100 Mbit/s network having special connectors (“D” coded 4-pin M12 connector according to
IEC 61076-2-101). The imc IPTCom Interface is equipped with a RJ45 connector and requires an adaptor. 
Software and operation:
· The imc IPTCom Interface is fully supported by the measurement system’s imc STUDIO operating software
· The IPTCom-Protocol comprises two main protocols: IP-ProcessData and IP-MessageData.
· An IPTCom-Client is implemented, which is only able to read IP-ProcessData. These data can be captured as
an imc channel, e.g. as time stamped signed INT16/FLOAT channels.
· This IPTCom-Protocol is at the moment specifically implemented and tested for BOMBARDIER. If you have
questions for your own compatibility, please do not hesitate to contact us.
Isolation strength:
· 60 V to system ground (case, CHASSIS)
