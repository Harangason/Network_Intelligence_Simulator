11.4 Active communication mode 
11.4.1 Initialisation 
The application switches to Initiator for the active communication mode and may select a bit rate; fc/128, fc/64 
or fc/32. 
11.4.2 Active communication mode RFCA 
The RFCA shall be executed according to the timing chart in Figure 11. 
− The Initiator shall perform the initial RFCA. 
− The first command sent by the Initiator shall be an ATR_REQ in the active communication mode at a 
selected bit rate. 
− The Initiator shall switch off the RF field and respect tRF_OFF after any command is sent in active 
communication mode. 
− The Target performs the response RFCA. 
− The Target sends the ATR_RES as a response to the ATR_REQ in the same bit rate as it has received the 
ATR_REQ and switch of the RF field respecting tRF_OFF after any command is sent in active communication 
mode. 
− The Initiator performs the response RFCA with n = 0. 
− The Initiator sends the PSL_REQ in order to change parameter or sends the DEP_REQ to start the data 
exchange protocol. 
 
Figure 11 — Initialisation flow for active communication mode 
tRF_OFF is the time between the start of the rising edge of the last modulation and the start of falling edge when 
the device turns off the RF field and should be in the range of 
− 350/fc < tRF_OFF ≤ 2 559/fc for a bit rate of fc/128, and 
− 215/fc < tRF_OFF ≤ 2 559/fc for a bit rate of fc/64 or fc/32.
