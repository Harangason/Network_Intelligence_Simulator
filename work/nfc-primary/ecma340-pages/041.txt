Table 9 — Coding of the PFB bits 8 to 6 
bit 8 bit 7 bit 6 PFB 
0 0 0 Information pdu 
0 0 1 Protected pdu 
0 1 0 ACK/NACK pdu 
1 0 0 Supervisory pdu 
Other settings are RFU 
 
Figure 31 specifies the structure of the Information pdu: 
 
Figure 31 — Information pdu 
— bit 8 to bit 6: Shall be set to all ZEROs. 
— bit 5: If bit set to ONE then it indicates Multiple Information (MI) chaining activated.  
— bit 4: If bit set to ONE then it indicates NAD available. 
— bit 3: If bit set to ONE then it indicates DID available. 
— bit 2 and bit 1: PNI packet number information. 
The Packet Number Information (PNI) counts the number of packets sent by the Initiator to the Target and vice 
versa starting by 0. These bytes are used for error detection during the protocol handling.  
Figure 32 specifies the structure of the ACK/NACK pdu. 
 
Figure 32 — ACK/NACK pdu 
— bit 8: Shall be set to ZERO. 
— bit 7: Shall be set to ONE. 
— bit 6: Shall be set to ZERO. 
— bit 5: If bit set to ONE then it indicates NACK, otherwise ACK. 
— bit 4: If bit set to ONE then it indicates NAD available. 
— bit 3: If bit set to ONE then it indicates DID available. 
— bit 2 and bit 1: PNI packet number
