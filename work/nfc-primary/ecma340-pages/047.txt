12.8.2.1.2 Definition of DSL_REQ bytes 
CMD 1: Shall be set to ‘D4’. 
CMD 2: DSL_REQ 
The DSL_REQ byte specifies the command deselect for the Initiator device. The value of DSL_REQ shall be 
‘08’. 
Byte 1: DID 
The DID shall be the same as defined during ATR or WUP commands. 
12.8.2.2 Deselect response (DSL_RES) 
12.8.2.2.1 General 
Figure 38 specifies the Deselect Response command DSL_RES. The DSL_RES is the response to the 
DSL_REQ and is sent from the Target to the Initiator. 
 
Figure 38 — Structure of the DSL_RES 
12.8.2.2.2 Definition of Deselect Response bytes 
CMD 1: Shall be set to ‘D5’. 
CMD 2: DSL_RES 
The DSL_RES byte specifies the command deselect response for the Target device. The value of DSL_RES 
shall be ‘09’. 
Byte 1: DID 
The DID shall be the same as in DSL_REQ. 
12.8.2.3 Handling of DSL_REQ and DSL_RES 
12.8.2.3.1 Initiator rules 
When the Initiator has sent a DSL_REQ and received a valid DLS_RES, the Target has been successfully 
halted. The DID assigned to the Target has been released.
