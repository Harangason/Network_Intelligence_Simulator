11.5.3  Power-down sequences
During power-down sequence, VEN shall always be set low before VDD(PAD) is shut down.

11.5.4  Download mode
PN7160 offers the possibility to download EEPROM with upgrades using the host interface commands, see ref.
[6] for more details.
To enter this mode, the pin DWL_REQ shall be pulled to VDD(PAD) before reset via VEN pin is done.
