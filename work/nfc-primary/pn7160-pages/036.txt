11.6.1.2  R/W mode for NFC Forum Type 3 Tag, FeliCa communication mode
The R/W mode for NFC Forum Type 3 Tag (T3T) is the general Reader/Writer to card communication
scheme according to the FeliCa specification. Figure 27 describes the communication on a physical level, the
communication overview describes the physical parameters.
