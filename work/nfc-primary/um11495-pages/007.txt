2.4  Combined modes of operation
More details can be found in Section 11 about the startup sequence and the API used in each of these modes.
In any NCI mode, PN7160 is capable of combining basic modes of operation described above, using the RF
Discovery as defined in NCI. The principle used to combine the various modes of operation is to build a cyclic
activity, which will sequentially activate various modes of operation:
1. Start a Polling sequence, to look for a remote Tag/Card or a remote Peer (Target). If several technologies
are enabled by the DH, PN7160 will poll sequentially for all the enabled technologies.
2. If nothing was detected, enter a Listening sequence, to potentially be activated as a Card emulator or a P2P
target by an external Reader/Writer or Peer.
3. If nothing happens after a programmable timeout, switch back to Poll Mode in step 1.
