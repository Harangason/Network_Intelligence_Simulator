Note:  It may happen that PN7160 has an NCI Message ready to be sent to the DH while it is receiving
another NCI Message from the DH. In such a condition, the IRQ pin will be raised somewhere during the Write
Sequence: this is not an error and has to be accepted by the DH: once the Write Sequence is completed, the
DH has to start a Read Sequence.
Issues may happen, in case PN7160 is in standby mode when the DH is writing a new frame: in such a
condition, PN7160 will not be able to catch the received frame.
In order to detect that PN7160 is not ready to receive a frame, the DH has to monitor the MISO line, to check
the value of the 1st Byte received on MISO while it is writing data on the MOSI line. When the Write sequence
starts:
• If the first Byte received on MISO is 0xFF, PN7160 is ready and the Write sequence will proceed with no
issue.
• If the first Byte received on MISO is any other value than 0xFF, PN7160 is not ready to receive a new frame.
The DH has to resend the whole NCI frame, after a typical timeout of 5 ms.
