6.3  Whole sequence to prepare the PN7160 operation
After the Reset/Init sequence is passed, PN7160 requires several other steps before it is ready to start
operating as Reader/Writer, Card Emulator …
The simplest case is when the DH issues CORE_RESET_CMD command with Reset Type = Keep
Configuration.
Figure 34. Initialization sequence to prepare PN7160 operation (Keep Configuration)
In case of CORE_RESET_CMD command issued by the DH with Reset Type = Reset Configuration, the
entire configuration is lost so PN7160 needs to be reconfigured and various optional steps might be needed
depending on the targeted use case.
