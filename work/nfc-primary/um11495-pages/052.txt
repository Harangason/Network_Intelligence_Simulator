6.6  Dynamic LMA
The PN7160 supports Dynamic Load Modulation Amplitude for P2P Target passive and Card Emulation. This
feature is set thanks to DLMA_CTRL, DLMA_RSSI and DLMA_TX parameters (see Section 11.3).
Below is the detailed description of these 3 parameters.
