7.4  [PN7160-NCI] extension: 15693 and ICODE tags
The version 1.0 of the NCI standard allows the data exchange with a tag ISO 15693 by using the RF Frame
interface. No additional interface is needed for this protocol. However, the data mapping is not yet defined in
[NCI], therefore, NXP has defined it for [PN7160-NCI-1.0].
