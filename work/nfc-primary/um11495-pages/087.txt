10.5  [PN7160-NCI] extension: EMVCo Profile in Poll & Listen Modes
The EMVCo profiles are introduced in PN7160 for EMVCo compliancy. Indeed there are incompatibilities
between the RF Discovery activity as defined in the NFC Forum and the RF discovery defined in EMVCo
standard.
10.5.1  EMVCo profile in Poll Mode
10.5.1.1  Configuring PN7160 to implement the EMVCo polling algorithm
To be compliant to the EMVCo certification tests, the RF Discovery has to be configured so that only NFC-A and
NFC-B are supported in Poll phase and so that there is no Listen phase. So the DH has to send the following
command:
RF_DISCOVER_CMD( 2,
