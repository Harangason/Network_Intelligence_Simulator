Web Browser Configuration Tool
The Configuration Tool for the PRO-MUX-1 is built-in and can be accessed via the Ethernet connection.  
As the Configuration Tool is web based it is compatible with all popular web browsers and Operating 
Systems. 
 
An internet connection is not required to access the Configuration Tool.  
The default page displayed is the PRO-MUX-1 Configuration Tool ‘Home’ page. We strongly suggest 
bookmarking the ‘Home’ page in your web browser to allow quick and easy future access.
To access any of the PRO-MUX-1 setup pages, the user is required to log-in. This prevents unauthorised 
user access from modifying the PRO-MUX-1 configuration. The factory default log-in is “admin” for 
username and “admin” for password.  
All modifications to the PRO-MUX-1 settings, including any user defined ‘User Modes’ are automatically 
saved inside the PRO-MUX-1.
Standard Ethernet networks
If the PRO-MUX-1 is connected to an Ethernet network containing both DHCP and DNS servers, launch any 
popular web browser and enter ‘http://promux-xxxxxx’ into the address bar (replacing ‘xxxxxx’ with the actual 
product’s serial number).  It is important to include the ‘http://’ section of this address.  If it is missing, the 
browser will conduct a web search.
