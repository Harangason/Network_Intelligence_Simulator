2.5.6 NMEA output of invalid or unknown data
By default the receiver will not output invalid data. In such cases, it will output empty ﬁelds. See
NMEA protocol conﬁguration for options to adjust this behavior.
A valid position ﬁx is reported as follows:
$GPGLL,4717.11634,N,00833.91297,E,124923.00,A,A*6E
An invalid position ﬁx (but valid time) is reported as follows:
$GPGLL,,,,,124924.00,V,N*42
