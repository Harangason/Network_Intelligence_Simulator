2.8.3 RATE (PUBX,40)
2.8.3.1 Set NMEA message output rate
Message NMEA-PUBX-RATE
Set NMEA message output rate
Type Set
Comment Set/Get message rate conﬁguration (s) to/from the receiver.
• Send rate is relative to the event a message is registered on. For example, if the rate of a navigation
message is set to 2, the message is sent every second navigation solution.
Information Class/ID: 0xf1 0x40 Number of fields: 11
Structure $PUBX,40,msgId,rddc,rus1,rus2,rusb,rspi,reserved*cs\r\n
Example $PUBX,40,GLL,1,0,0,0,0,0*5D\r\n
Payload:
Field Name Format Unit Example Description
0 PUBX string - $PUBX Message ID, UBX protocol header, proprietary sentence
1 ID numeric - 40 Proprietary message identiﬁer
2 msgId string - GLL NMEA message identiﬁer
3 rddc numeric cycles 1 output rate on DDC
• 0 disables that message from being output on this
port
• 1 means that this message is output every epoch
