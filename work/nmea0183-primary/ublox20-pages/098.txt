3.15.12 UBX-NAV-PVT (0x01 0x07)
3.15.12.1 Navigation position velocity time solution
Message UBX-NAV-PVT
Navigation position velocity time solution
Type Periodic/polled
Comment This message combines position, velocity and time solution, including accuracy ﬁgures.
Note that during a leap second there may be more or less than 60 seconds in a minute.
See description of leap seconds in the integration manual for details.
