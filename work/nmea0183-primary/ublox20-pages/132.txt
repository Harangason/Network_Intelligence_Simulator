3.17.3 UBX-SEC-SIGLOG (0x27 0x10)
3.17.3.1 Signal security log
Message UBX-SEC-SIGLOG
Signal security log
Type Periodic/polled
Comment This message provides a log of past signal security related events, that is, events related to jamming and
spooﬁng. Each event is a combination of a detection type and a event type, where the event type 'indication
started' and 'indication stopped' and also the event type 'indication triggered' and 'indication timed-out' form
a pair. A maximum of 16 events are logged; after the log is ﬁlled, recent events take precedence over past
events in the log. Power cycles and restarts of the receiver reset the log, deleting its content.
Note: It is advised not to restart the receiver while it's indicating spooﬁng.
