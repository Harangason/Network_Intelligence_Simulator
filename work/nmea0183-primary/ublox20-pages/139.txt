4 RTCM protocol
4.1 RTCM introduction
The RTCM (Radio Technical Commission for Maritime Services) protocols are used to supply the
GNSS receiver with real-time diﬀerential correction data. The RTCM protocol speciﬁcations are
available from http://www.rtcm.org.
The RTCM 3.x support is implemented according to RTCM Standard 10403.4 Recommended
Standards for Differential GNSS (Global Navigation Satellite Systems) Service, Version 3.
4.2 RTCM 3.x conﬁguration
The conﬁguration of RTCM 3.x input or RTCM 3.x output (if available) is further detailed in the
integration manual for typical applications.
The RTCM 3.x protocol can be disabled/enabled on communication interfaces using the
Conﬁguration interface, for example conﬁguration item CFG-UART1INPROT-RTCM3X.
