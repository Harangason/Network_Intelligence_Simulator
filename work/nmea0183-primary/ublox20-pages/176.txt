6.9.10 CFG-MOT: Motion detector conﬁguration
The items in this group specify the parameters used for the internal receiver motion detector. The
platform motion is assessed by combining the detected motion of diﬀerent detectors looking at
speciﬁc data types (i.e. GNSS, gyroscopes, accelerometers, wheel ticks). The decision thresholds of
the internal detectors can be speciﬁed using the conﬁguration items in this group.
Conﬁguration item Key ID Type Scale Unit Description
CFG-MOT-GNSSSPEED_THRS 0x20250038 U1 0.01 m/s Static hold speed threshold, below which the
receiver is considered to be stationary
Set this parameter to 0 to enable the default ﬁrmware value or behavior.
CFG-MOT-GNSSDIST_THRS 0x3025003b U2 1.0 m Static hold distance threshold, within which the
receiver is considered to be stationary
Set this parameter to 0 to enable the default ﬁrmware value or behavior.
