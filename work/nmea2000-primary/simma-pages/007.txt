3.2 Function APIs 
 
  can_init 
 
            Function Prototype: 
               void can_init( void ); 
 
            Description: 
can_init initializes the CAN peripheral for reception and transmission of CAN 
frames at a network speed of 250 kbps.  Any external hardware that needs to be 
initialized can be done inside of can_init.  The sample point should be as close 
to 0.875 as possible, but should not exceed it. 
 
          Parameters: 
               void 
 
          Return Value: 
             void
