  n2000_tx_sf 
 
            Function Prototype: 
               uint8_t n2000_tx_sf ( n2000_t *msg ); 
 
            Description: 
Buffers a NMEA 2000 single frame message for transmission.  For messages 
that are larger than 8 bytes, use n2000_tx_tp() or n2000_tx_fp(). 
 
          Parameters: 
msg: Points to the NMEA 2000 message that should be transmitted. 
 
          Return Value: 
1: Message was not buffered for transmission. 
0: Message was buffered for transmission.
