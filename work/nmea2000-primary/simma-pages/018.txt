  n2000_tx_fp 
 
            Function Prototype: 
               uint8_t n2000_tx_fp ( n2000_t *msg, uint8_t seq ); 
 
            Description: 
Buffers a NMEA 2000 fast packet message for transmission.    This function is 
used for non-single-frame messages as defined by the NMEA 2000 application 
layer. 
 
          Parameters: 
msg: Points to the NMEA 2000 message that should be transmitted. 
seq: 8-bit sequence number ranging from 0 to 255.  seq needs to be unique for 
each fast packet PGN and is to be incremented for each successful transmission 
of a fast packet message. 
 
          Return Value: 
1: Message was not buffered for transmission. 
0: Message was buffered for transmission.
