  n2000_bip_tx_rate_max_get 
 
            Function Prototype: 
               uint8_t n2000_bip_tx_rate_max_get ( uint8_t p ); 
 
            Description: 
In order to implement babbling idiot protection, the NMEA 2000 module tracks 
how many messages are transmitted by the application in a 250 ms window.  
The application can use this function to retrieve the max bus load that has been 
imposed on the bus by the application.   
 
          Parameters: 
    p: Indicates which port to access. 
 
          Return Value 
0 to 100 percent
