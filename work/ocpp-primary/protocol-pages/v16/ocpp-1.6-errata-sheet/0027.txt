This is the TOTAL allowed charging power.
If used for AC Charging, the phase current should be calculated via: Current per phase = Power / (Line Voltage *

Added in errata sheet v3.0
There is no requirement that explains the obvious: The first ChargingSchedulePeriod should start with
StartSchedule = 0.

Old text Required. List of ChargingSchedulePeriod elements defining maximum power or current usage over time.
