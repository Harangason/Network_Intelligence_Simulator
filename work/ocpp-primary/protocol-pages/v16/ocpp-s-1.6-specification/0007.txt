2. Binding to Transport Protocol
This section describes how the OCPP PDUs can be conveyed over SOAP.
The rationale behind using SOAP as a transport is that SOAP already provides the infrastructure of
sending messages. SOAP has a good support in the industry, which results in tools that improve the
ease of implementing the protocol.
The used version of SOAP MUST be 1.2. See [SOAP]. Please note that this has no relationship with the
1.2 version number of the OCPP specification.
