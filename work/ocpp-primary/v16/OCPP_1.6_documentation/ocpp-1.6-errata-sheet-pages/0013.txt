request

The following note must be added at the end of this section:

If no fields are specified in the ClearChargingProfile.req message, then Charge Point SHALL
clear all ChargingProfiles. If one or more fields are specified in the ClearChargingProfile.req
message, then Charge Point SHALL clear all ChargingProfiles that match (logical AND) all of the
provided fields.
