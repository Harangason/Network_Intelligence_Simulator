dataType boolean
Description When true the Component exists and is locally configured/wired for use, but may
not be (remotely) Enabled.
This variable is required on any Component that can be reported by the Charging
Station. As a minimum it shall exist on ChargingStation, EVSE and Connector.
Note If any other variables are reported for a Component, then reporting Available does
not add much value and may be omitted. However, the variable needs to exist,
because it can be queried for by a GetCustomReport request for all Components
that are 'available'.
EVSE and Connector components are addressed on their respective tier. So,
EVSE #1 is addressed as component EVSE on tier "evse = 1" and connector #1 on
this EVSE is addressed as component Connector on tier "evse = 1, connector = 1.
