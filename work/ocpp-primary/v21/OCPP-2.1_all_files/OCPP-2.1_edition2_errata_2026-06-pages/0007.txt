Terminology and Conventions
Bold: when needed to clarify differences, bold text might be used.
The errata entries are sorted by page number of the affected section of the specification document. When an errata entry affects
multiple parts of the specification, then the various changes are grouped together with subsections referring to the pages affected
by those changes.
This is version 2026-06 of the errata. The errata of this version are marked with "(2026-06)" in the section title.
In some cases the issue number by which it was reported, is added in square brackets at the end of the section title, e.g. "[349]". For
retrieval of the issue in the issue tracking system prefix the number with "OCPP20M", like "[OCPP20M-349]".
