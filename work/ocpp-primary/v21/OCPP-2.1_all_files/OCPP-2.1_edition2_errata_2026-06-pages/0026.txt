Description By default, a protocol listed in ISO15118Ctrlr.ProtocolSupported is enabled,
unless an instance of ISO15118Ctrlr.ProtocolEnabled with the same instance
name exists that has a value of false. In that case the protocol mentioned in
ISO15118Ctrl.ProtocolSupported with the same instance is explicitly disabled
and cannot be used.
ProtocolEnabled shall always have the same number of instances and the same
instance names as ProtocolSupported, such that instance "1" of ProtocolEnabled
matches with instance "1" of ProtocolSupported and instance "2" of
ProtocolEnabled matches with instance "2" of ProtocolSupported, and so on.
Below example shows how the ISO 15118-20:DC protocol can be disabled, even
though it is supported:
Example: Charging Station supports ISO 15118-2 and ISO 15118-20 DC
- ISO15118Ctrlr.ProtocolSupported["1"] = "urn:iso:15118:2:2013:MsgDef,2,0"
- ISO15118Ctrlr.ProtocolSupported["2"] = "urn:iso:std:iso:15118:-20:DC,1,0"
CSO disables ISO 15118-20 DC:
- ISO15118Ctrlr.ProtocolEnabled["1"] = true
- ISO15118Ctrlr.ProtocolEnabled["2"] = false
