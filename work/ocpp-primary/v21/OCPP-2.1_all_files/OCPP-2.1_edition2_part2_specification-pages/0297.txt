8 Remarks Only one tariff structure can be sent in a message, because a tariff structure can potentially be

Sending a SetDefaultTariffRequest with evseId = 0 basically copies the tariff to each EVSE of the
Charging Station.
A tariffId uniquely identifies the tariff for the Charging Station. An updated default tariff must
therefore have a new tariffId. In order to update the default tariff per a certain date, a new default
tariff can be installed with a validFrom date after which it becomes valid and replaces the existing
default tariff.
