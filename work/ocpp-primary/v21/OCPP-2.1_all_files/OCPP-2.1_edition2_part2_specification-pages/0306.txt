Scenario description Charging Station has 2 EVSEs
1. CSMS sends SetDefaultTariffRequest for tariffId = "Default01" with validFrom = "2024-01-
01T00:00:00Z" to evseId = 0 (all EVSEs).
a. Charging Station accepts with SetDefaultTariffResponse.
2. Charging Station sends AuthorizeRequest for idToken = "ABCD1234".
a. CSMS responds with AuthorizeResponse with tariffId = "MSP01" and authorizes
idToken.
b. Charging Stations starts a transaction for idToken on EVSE #1.
3. Charging Station sends AuthorizeRequest for idToken = "FBFB0000".
a. CSMS responds with AuthorizeResponse with tariffId = "MSP02" and authorizes
idToken.
4. CSMS sends GetTariffsRequest with evseId = 0 to Charging Station before a transaction is
started on EVSE #2 and before and EVConnectionTimeout has occurred.
5. Charging Station returns a GetTariffsResponse with all default tariffs and driver-specific
tariffs that are present on the Charging Station in an array of tariffAssignments:
◦ tariffId = "Default01", tariffKind = DefaultTariff, validFrom = "2024-01-
01T00:00:00Z", evseIds = [1, 2]
◦ tariffId = "MSP01", tariffKind = DriverTariff, evseIds = [1], idTokens =
["ABCD1234"]
◦ tariffId = "MSP02", tariffKind = DriverTariff, idTokens = ["FBFB0000"]
5 Prerequisites Local cost calculation is supported.
