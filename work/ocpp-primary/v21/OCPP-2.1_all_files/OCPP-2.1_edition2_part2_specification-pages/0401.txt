K18 - ISO 15118-20 Scheduled Control Mode
New in OCPP 2.1
No. Type Description
1 Name ISO 15118-20 Scheduled Control Mode
2 ID K18
3 Objective(s) To describe the charging process when Charging Stations uses ISO 15118-20 with scheduled
control mode
4 Description CSMS provides a charging profile with up to three charging schedules and optional price
information that try to match the energy needs of EV. EV selects a charging schedule to follow
and returns its calculated charging schedule back to Charging Station.
Actors EV, Charging Station, CSMS.
