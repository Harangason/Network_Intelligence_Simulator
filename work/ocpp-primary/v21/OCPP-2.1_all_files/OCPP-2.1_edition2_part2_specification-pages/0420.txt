8 Remarks When an EMS provides frequent updates to a power limit, instead of providing a schedule, then
each update would result in Charging Station having to replace the existing
ChargingStationExternalConstraints charging profile by a new one. When using a
Dynamic charging profile Charging Station only has to update the value of limit or setpoint of the
existing charging profile.
It is advised to have a charging profile with a lower stack level present to fall back to, in case the
dynamic charging profile is invalidated, because no update is provided within duration seconds.
