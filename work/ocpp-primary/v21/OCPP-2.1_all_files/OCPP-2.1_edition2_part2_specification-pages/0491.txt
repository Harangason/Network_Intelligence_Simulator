params.values is greater than 0
Charging Station SHALL send no more than params.values

N15.FR.08 If params.values in a SetMonitoringDataType of
a monitor is greater than 0
Charging Station SHALL send a NotifyPeriodicEventStream
message for the associated monitor as soon as params.values
values are available.

NotifyPeriodicEventStream message to the timestamp of the
first value in the data list of values. (This effectively makes that
the offset t of the first value is always 0).
