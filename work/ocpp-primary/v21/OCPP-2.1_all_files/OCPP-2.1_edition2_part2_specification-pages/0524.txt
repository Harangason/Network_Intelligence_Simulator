Q01.FR.03 Q01.FR.02 Charging Station SHALL send a
NotifyEVChargingNeedsRequest with
evseId set to the EVSE used for this
transaction AND

and Charging Station AND
a list of availableEnergyTransfer that is

the fields controlMode,
v2xChargingParameters and optionally
departureTime, mobilityNeedsMode
and evEnergyOffer.

Q01.FR.07 If CSMS accepts the
requestedEnergyTransfer
CSMS SHALL respond with a
NotifyEVChargingNeedsResponse
with status = Accepted if able to
provide a charging profile
immediately, or Processing if more
time is needed to provide a charging
profile.
See requirements K18/19.FR.03 and
K18/19.FR.05.
Charging station can expect to receive
a charging profile immediately or
soon.
Q01.FR.08 Charging Station’s
ISO15118Ctrlr.Enabled = true and
V2XChargingCtrlr.Enabled = true AND
CSMS receives an AuthorizeRequest
AND
CSMS is not able to determine a list of
allowedEnergyTranfer before sending
the AuthorizeResponse
CSMS SHALL omit
allowedEnergyTransfer from
AuthorizeResponse.
This can happen if it could not be
determined within the short time span
before the response has to be
returned, e.g. because a third party
has to be requested for permission.

NotifyEVChargingNeedsRequest with

transaction and
requestedEnergyTransfer set to its
default energy transfer (charging only
AC/DC) and availableEnergyTransfer
set to the supported energy transfers.

AC_single_phase, AC_two_phase,
AC_three_phase or DC, DC_ACDP
