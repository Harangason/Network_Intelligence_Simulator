ID Precondition Requirements Note
Q05.FR.01 When a ChargingSchedulePeriodType
with operationMode =
ExternalSetpoint in a TxProfile
or TxDefaultProfile charging
profile becomes active
Charging Station SHALL use the value from the
External System for setpoint and setpointReactive.
During this period the
values of setpoint and
setpointReactive are
given by External
System. When applicable
this also includes the L2
and L3 values of
setpoint(Reactive).
Q05.FR.02 When a ChargingSchedulePeriodType
with operationMode =
ExternalLimits in a TxProfile or
TxDefaultProfile charging profile
becomes active
Charging Station SHALL use the value from the
External System for limit and dischargeLimit.
During this period the
values of limit and
dischargeLimit are given
by External System.
When applicable this
also includes the L2 and
L3 values of
(discharge)Limit.
Q05.FR.03 Q05.FR.01 AND
chargingProfileKind = Dynamic
External System MAY dynamically change setpoint
and setpointReactive during the
ChargingSchedulePeriodType.
When applicable this
also includes the L2 and
L3 values of
setpoint(Reactive).
Q05.FR.04 Q05.FR.02 AND
chargingProfileKind = Dynamic
External System MAY dynamically change limit and
dischargeLimit during the
ChargingSchedulePeriodType.
When applicable this
also includes the L2 and
L3 values of
(discharge)Limit.
Q05.FR.05 Q05.FR.03 AND
External System updates setpoint or
setpointReactive
Charging station SHALL update setpoint or
setpointReactive in the charging profile and set
dynUpdateTime to the current time.
Q05.FR.06 Q05.FR.04 AND
External System updates limit or
dischargeLimit
Charging station SHALL update limit or
dischargeLimit in the charging profile and set
dynUpdateTime to the current time.
Q05.FR.07 ( Q05.FR.03 OR Q03.FR.04 ) AND
chargingSchedule.duration is set AND
current time >
(chargingSchedule.duration +
dynUpdateTime)
Charging Station SHALL consider the charging
profile invalid and switch to using the next valid
charging profile.
This is a fallback when
External System is no
longer responding within
time set by duration.
Q05.FR.08 Q05.FR.07 AND
Charging Station receives an update
for limit, dischargeLimit or setpoint
from External System
Charging Station SHALL consider the charging
profile eligible again as a valid profile.
This means the charging
profile is valid again
when a new update is
received, assuming there
is no other charging
profile of higher stack
level.

System

No. Type Description
1 Name External V2X control with a charging profile from an External System
2 ID Q06
