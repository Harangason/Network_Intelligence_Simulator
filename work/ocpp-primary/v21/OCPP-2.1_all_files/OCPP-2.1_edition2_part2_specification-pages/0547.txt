Q09.FR.03 During a ChargingSchedulePeriodType
with operationMode =
LocalLoadBalancing
Charging Station SHALL continously read the power
reported by the upstream grid meter
Q09.FR.04 Q09.FR.03 Charging Station SHALL calculate the power
setpoint as follows:
If Load > UpperThreshold
    DeltaSetpoint =
        UpperThreshold
        + UpperOffset - Load
Else If Load <
LowerThreshold
    DeltaSetpoint =
        LowerThreshold
        + LowerOffset - Load
Else
    DeltaSetpoint = 0
setpoint = setpoint
        + DeltaSetpoint
"Load" is power from
upstream meter. Positive
values for consumption
of energy.
Q09.FR.05 Q09.FR.03 AND
limit and/or dischargeLimit are set
Charging Station SHALL cap the maximum
(positive) value of setpoint to the value of limit and
cap the minimum (negative) value of setpoint to the
value of dischargeLimit.
This also applies to L2
and L3 values.
