1.2. AFRRSignal
1.2.1. AFRRSignalRequest
(2.1) This message passes an aFRR signal on to the charging station. Charging station uses the value of signal to select a
matching power value from the v2xSignalWattCurve in the ChargingSchedulePeriod.
Class
Field Name Field Type Card. Description
timestamp dateTime 1..1 Required. Time when signal becomes active.
