2.105. TaxRateType
Class
Tax percentage
TaxRateType is used by: Common:PriceType , Common:TariffEnergyType , Common:TariffFixedType , Common:TariffTimeType
Field Name Field Type Card. Description
type string[0..20] 1..1 Required. Type of this tax, e.g. "Federal ", "State", for
information on receipt.
tax decimal 1..1 Required. Tax percentage
stack integer, 0 <= val 0..1 Optional. Stack level for this type of tax. Default value,
when absent, is 0.
stack = 0: tax on net price;
stack = 1: tax added on top of stack 0;
stack = 2: tax added on top of stack 1, etc.
