2.1.8. NetworkConfiguration
New in OCPP 2.1
NOTE For improved readability the variables below are listed in a concise format.
The component NetworkConfiguration represents network connection configurations. Its values can be set via
SetNetworkProfileRequest message, or when its variables are reported as writable, directly via SetVariablesRequest messages. The
component instance of NetworkConfiguration is the same as the configurationSlot parameter of a SetNetworkProfileRequest.
The component NetworkConfiguration is located at the top tier, i.e. not assigned to a specific EVSE.
