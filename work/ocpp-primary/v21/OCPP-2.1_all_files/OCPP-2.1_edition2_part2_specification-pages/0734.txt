For the variables in NetworkConfiguration that are identical to parameters of SetNetworkProfileRequest, the same types and limits
are used.
If the Charging Station only supports setting the network configuration via the SetNetworkProfileRequest, then all variables are
reported as ReadOnly, except for BasicAuthPassword which must be omitted.
If the Charging Station supports setting the network configuration via this NetworkConfiguration component, then all variables are
reported as ReadWrite, except for BasicAuthPassword which must be WriteOnly.
