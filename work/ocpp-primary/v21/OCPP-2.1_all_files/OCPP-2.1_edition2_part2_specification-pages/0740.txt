Description Configured current local time offset in the format: "+01:00", "-02:00" etc.
When a TimeOffset is used, it is advised not to implement: TimeZone. If a
Charging Station has implemented both TimeOffset and TimeZone it is
RECOMMENDED to not use both at the same time.
The time offset is for display purposes to show local time and is also used for
charging profiles that have useLocalTime = true.
