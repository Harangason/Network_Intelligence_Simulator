Description This configuration variable defines how long the Charging Station has to wait
before generating another CSR, in the case the CSMS accepts the
SignCertificateRequest, but never returns the signed certificate back. This value
will be doubled after every attempt. The amount of attempts is configured at
CertSigningRepeatTimes If the certificate signing process is slow, this setting
allows the CSMS to tell the Charging Station to allow more time.
