Description This variable allows a Charging Station to support non-compliant OCPP behavior
and connect to a CSMS that uses a wildcard TLS server certificate for the OCPP
connection.
If this variable is present it SHALL be ReadWrite. If this variable is not
implemented or has value false, the OCPP-compliant behavior is that a Charging
Station rejects a connection from a CSMS that presents a wildcard certificate.
It is highly RECOMMENDED to not allow wildcard certificates.
