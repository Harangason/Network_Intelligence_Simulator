Description When set to true this instructs the Charging Station to not issue any
AuthorizationRequests, but only use Authorization Cache and Local Authorization
List to determine validity of idTokens.
Note: The difference between AuthCtrlr.DisableRemoteAuthorization and
AuthCacheCtrlr.DisablePostAuthorization is that the latter only disables re-
authorization of tokens that are as not-Accepted in the Authorization Cache or
Local Authorization List, whereas AuthCtrlr.DisableRemoteAuthorization
disables all authorization with CSMS.
