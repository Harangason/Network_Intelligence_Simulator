Description Indicates whether a Charging Station allows an external system to submit limits
to be represented as a ChargingStationExternalConstraints charging
profile.
When false or absent this configuration variable allows that
ChargingStationExternalConstraints charging profiles are created.
When true this forbids the creation of a
ChargingStationExternalConstraints charging profile. In that case the
only way for an external system to influence charging is when CSMS explicitly
allows this during a charging profile with a schedule that contains an
ExternalLimits or ExternalSetpoint period.
