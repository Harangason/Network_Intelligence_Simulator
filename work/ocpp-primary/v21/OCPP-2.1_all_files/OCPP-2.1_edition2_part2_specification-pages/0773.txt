Description If an instance of this variable is true, then charging profiles with the
chargingProfilePurpose mentioned in the variableInstance are persistent, i.e. they

When these variables are not present or false, then these profiles are not stored
in persistent memory.
Note: ChargingStationMaxProfile, TxDefaultProfile and PriorityCharging are
