Description Message (and/or tariff information) to be shown to an EV Driver when Charging
Station is offline. Language codes shall be specified as RFC5646. The short form
is allowed if no regional variant is needed. For example: "en" (English), "es"
(Spanish), "fr" (French).
As instances aren’t dynamic in the device model, the station will need to expose
all languages that it supports.
A Charging Station that has no language support and does not support multiple
languages should report a single variable without an instance.
