Description Interval specifies the maximum interval in seconds to use when evaluating the
conditions regarding current, power and energy of a tariff element during a
transaction. The value of minLimit given by Charging Station specifies the
minimal interval that Charging Station will accept.
A value of Interval[Tariff] of 0 means Charging Station will evaluate current,
power and energy values using the shortest interval possible for this Charging
Station.
