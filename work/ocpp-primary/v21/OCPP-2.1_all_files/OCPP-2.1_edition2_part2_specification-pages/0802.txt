2.17.5. V2X Additional Sampled Data Measurands
The following configuration variables define parameters that the Charging Station shall report via TransactionEventRequest
messages in addition to those measurands that have been defined in the standard SampledDataCtrlr. The sampling interval for
these additional measurands is configured in V2XChargingCtrlr.TxUpdatedInterval. When absent, the interval value from
SampledDataCtrlr.TxUpdatedInterval is used.
