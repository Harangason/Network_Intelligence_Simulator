Network Profile slot
Test case name Set new NetworkConnectionProfile - Prevent overwriting configured Network Profile slot
Test case Id TC_B_108_CS
Use case Id(s) B09
Requirement(s) B09.FR.22
System under test Charging Station
Description The CSMS updates the connection details on the Charging Station. For instance in preparation of a
migration to a new CSMS.
Purpose To verify that the Charging Station does not allow to change the configuration of a network slot that is in
NetworkConfigurationPriority, which may be used during reconnection.
Prerequisite(s) NetworkConfiguration component variables are writable.
