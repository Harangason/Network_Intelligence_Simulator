Test case name Set Charging Profile - maxOfflineDuration
Test case Id TC_K_100_CS
Use case Id(s) K01
Requirement(s) K01.FR.101, K01.FR.102, K01.FR.103

Description To enable the CSMS to influence the charging power or current drawn from a specific EVSE or the entire
Charging Station over a period of time. The CSMS sends a SetChargingProfileRequest to the Charging
Station to influence the power or current drawn by EVs.
Purpose To verify if the Charging station stops using the charging profile when Charging station is longer offline
than specified in the charging profile’s maxOfflineDuration.
