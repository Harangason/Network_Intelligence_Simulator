TC_K_102_CS: Set Charging Profile - limitAtSoc
Test case name Set Charging Profile - limitAtSoc
Test case Id TC_K_102_CS
Use case Id(s) K01
Requirement(s) K01.FR.100
System under test Charging Station
Description To enable the CSMS to influence the charging power or current drawn from a specific EVSE or the entire
Charging Station over a period of time. The CSMS sends a SetChargingProfileRequest to the Charging
Station to influence the power or current drawn by EVs.
Purpose To verify if the Charging station caps the charging speed when reaching specified limitAtSoc.
Prerequisite(s) - Charging station supports receiving SoC from the EV. e.g. by CHaDeMo, ISO15118-2 or ISO15118-20
- SmartChargingCtrlr.SupportsFeature[LimitAtSoC] is true
