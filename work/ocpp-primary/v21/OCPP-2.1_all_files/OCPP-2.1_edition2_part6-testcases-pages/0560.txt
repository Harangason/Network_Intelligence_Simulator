TC_K_110_CS: EMS Control - Set Charging Profile - MaxExternalConstraintsId -
validations
Test case name EMS Control - Set Charging Profile - MaxExternalConstraintsId - validations
Test case Id TC_K_110_CS
Use case Id(s) K01
Requirement(s) K01.FR.81
System under test Charging Station
Description To enable the CSMS to influence the charging power or current drawn from a specific EVSE or the entire
Charging Station over a period of time. The CSMS sends a SetChargingProfileRequest to the Charging
Station to influence the power or current drawn by EVs.
Purpose To verify if the Charging station validates Charging Profile ids being set when MaxExternalConstraintsId is
configured.
Prerequisite(s) Charging station supports Component Variable SmartChargingCtrlr.MaxExternalConstraintsId.
