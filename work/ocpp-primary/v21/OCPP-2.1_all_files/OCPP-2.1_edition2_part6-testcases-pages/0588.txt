Test case name Dynamic charging profiles by external system - Dynamic charging profile configured
Test case Id TC_K_125_CS
Use case Id(s) K29
Requirement(s) K29.FR.01, K29.FR.02, K29.FR.03, K29.FR.05, K29.FR.06
System under test Charging Station
Description To allow a dynamically changing limit in a charging profile from an external system.
Purpose To verify if the Charging Station is able to inform the CSMS when it’s capacity is being throttled by a locally
connected EMS.
Prerequisite(s) - The Charging Station is connected locally to a system which can apply charging limit constraints.
- External connected system hasn’t set any limit on the charger.
