TC_K_136_CS: Set Charging Profile - Local time - TimeZone
Test case name Set Charging Profile - Local time - TimeZone
Test case Id TC_K_103_CS
Use case Id(s) K01
Requirement(s) K01.FR.90
System under test Charging Station
Description To enable the CSMS to set charging profiles with local times so the charging power can be influences on
local time base independent on DST.
Purpose To verify if the Charging station is able to calculate the Zulu time from a chargingProfileSchedule using
local times.
Prerequisite(s) - SmartChargingCtrlr.SupportsFeature[UseLocalTime] is true
- ClockCtrlr.TimeZone is present
Before (Preparations)
Configuration State:
- ClockCtrlr.TimeZone is "" (if present)
Memory State:
N/a
Reusable State:
N/a
