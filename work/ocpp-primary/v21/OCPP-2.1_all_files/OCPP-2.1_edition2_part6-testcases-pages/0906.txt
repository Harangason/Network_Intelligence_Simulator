Test case name Battery Swap - Charging - Battery Swap Charging
Test case Id TC_S_105_CS
Use case Id(s) S01, S04
Requirement(s) S01.FR.01, S03.FR.01, S03.FR.02, S03.FR.03, S04.FR.01, S04.FR.02, S04.FR.07, S04.FR.06
System under test Charging Station
Description Charging station is able to support battery swapping.
Purpose To verify whether the Charging Station communicates the status changes correctly to the CSMS during the
charging process.
Prerequisite(s) Charging Station supports battery swapping (BatterySwapCtrlr.Available is true)
One battery with less or equal SoC than 96 percent
