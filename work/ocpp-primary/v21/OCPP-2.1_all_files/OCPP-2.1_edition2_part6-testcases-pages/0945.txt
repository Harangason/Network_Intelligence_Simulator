MonitoringReportCommunicated
State MonitoringReportCommunicated
System under test Charging Station
Description Retrieves the full monitoring report from a Charging Station and makes it available for usage in test cases.
It is possible to specify reset to a specific MonitoringBase before retrieving the MonitoringReport using the
argument.
Argument is exposed variable <resetToMonitoringBase> and has valid values:
- All - set monitoring base to All
- FactoryDefault - set monitoring base to FactoryDefault
- HardWiredOnly - set monitoring base to HardWiredOnly
- NoReset - do not set monitoring base
If argument is not specified NoReset will be assumed.
Exposes <monitoringReportData>
