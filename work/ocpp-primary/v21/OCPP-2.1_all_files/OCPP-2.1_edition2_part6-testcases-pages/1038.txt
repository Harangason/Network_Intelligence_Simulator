TC_C_118_CSMS: Settlement at end of transaction - settled by CS, receipt by
CSMS
Test case name Settlement at end of transaction - settled by CS, receipt by CSMS
Test case Id TC_C_118_CSMS
Use case Id(s) C21
Requirement(s) C21.FR.03
System under test CSMS
Description In order to test that Charging Station supports settlement at the end of a transaction where the settlement
is handled by the Charging Station and the receipt is provided by the CSMS.
Purpose To verify that the CSMS can properly handle a transaction where the settlement is done by the Charging
Station and the CSMS provides the receipt.
Prerequisite(s) - CSMS supports settlement at the end of a transaction. - CSMS supports Charging Stations with integrated
payment terminals.
- Test System has PaymentCtrlr.Enabled = true
- Test System has PaymentCtrlr.AuthorizeDirectPayment = false
- Test System has PaymentCtrlr.AuthorizationAmount = 50.00
- Test System has PaymentCtrlr.PaymentDetails = "CardLast4Digits"
- Test System has PaymentCtrlr.SettlementByCSMS = false
- Test System has PaymentCtrlr.ReceiptByCSMS = true
- CSMS lets the CS handle the settlement at the end of a transaction, but the CSMS provides receipts.

Charging Station CSMS

transactionInfo.transactionLimit.maxCost 50.00
