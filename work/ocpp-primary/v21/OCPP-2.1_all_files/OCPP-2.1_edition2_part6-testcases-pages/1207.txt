TC_K_100_CSMS: Set Charging Profile - maxOfflineDuration
Test case name Set Charging Profile - maxOfflineDuration
Test case Id TC_K_100_CSMS
Use case Id(s) K01
Requirement(s)
System under test CSMS
Description To enable the CSMS to influence the charging power or current drawn from a specific EVSE or the entire
Charging Station over a period of time. The CSMS sends a SetChargingProfileRequest to the Charging
Station to influence the power or current drawn by EVs.
Purpose To verify if the CSMS is able to specify a maxOfflineDuration and invalidAfterOfflineDuration the charging
profile.

Charging Station CSMS
Manual Action: Request the CSMS to send a TxDefaultProfile charging profile with a maxOfflineDuration and
invalidAfterOfflineDuration set to true
2. The Test System responds with a
SetChargingProfileResponse with
status Accepted
1. The CSMS sends a SetChargingProfileRequest
Tool validations
* Step 1:
Message SetChargingProfileRequest
- chargingProfile.chargingProfilePurpose must be TxDefaultProfile
- chargingProfile.maxOfflineDuration must be <not omitted>
- chargingProfile.invalidAfterOfflineDuration must be true
