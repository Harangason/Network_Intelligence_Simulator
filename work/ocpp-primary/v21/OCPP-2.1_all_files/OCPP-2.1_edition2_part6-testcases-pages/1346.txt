TC_Q_110_CSMS: Central V2X control with dynamic CSMS setpoint - pull
Test case name Central V2X control with dynamic CSMS setpoint - pull
Test case Id TC_Q_110_CSMS
Use case Id(s) Q04, K28
Requirement(s) K28.FR.01, K28.FR.02, K28.FR.07, K28.FR.12
System under test CSMS
Description To enable the CSMS to influence the charging power or current drawn from a specific EVSE or the entire
Charging Station over a period of time. The CSMS sends a SetChargingProfileRequest to the Charging
Station to influence the power or current drawn by EVs. The CSMS calculates a ChargingSchedule to stay
within certain limits, which MAY be imposed by any external system.
Purpose To verify if the CSMS is able to support DynamicControl charging profiles and a CS is able to pull from
CSMS.
Prerequisite(s) - CSMS supports Bidirectional Power Transfer
