L536@P8: CRC Generation
L537@P8: CRC bytes are provided as part of the DS18B20’s 64-bit
L538@P8: ROM code and in the 9th byte of the scratchpad memory.
L539@P8: The ROM code CRC is calculated from the first 56 bits
L540@P8: of the ROM code and is contained in the most significant
L541@P8: byte of the ROM. The scratchpad CRC is calculated from
L542@P8: the data stored in the scratchpad, and therefore it changes when the data in the scratchpad changes. The CRCs
L543@P8: provide the bus master with a method of data validation
L544@P8: when data is read from the DS18B20. To verify that data
L545@P8: has been read correctly, the bus master must re-calculate
L546@P8: the CRC from the received data and then compare this
L547@P8: value to either the ROM code CRC (for ROM reads) or
L548@P8: to the scratchpad CRC (for scratchpad reads). If the calculated CRC matches the read CRC, the data has been
L549@P8: received error free. The comparison of CRC values and
L550@P8: the decision to continue with an operation are determined
L551@P8: entirely by the bus master. There is no circuitry inside the
L552@P8: DS18B20 that prevents a command sequence from proceeding if the DS18B20 CRC (ROM or scratchpad) does
L553@P8: not match the value generated by the bus master.
L554@P8: The equivalent polynomial function of the CRC (ROM or
L555@P8: scratchpad) is:
L556@P8: CRC = X8 + X5 + X4 + 1
L557@P8: The bus master can re-calculate the CRC and compare it
L558@P8: to the CRC values from the DS18B20 using the polynomial generator shown in Figure 11. This circuit consists
L559@P8: of a shift register and XOR gates, and the shift register
L560@P8: bits are initialized to 0. Starting with the least significant
L561@P8: bit of the ROM code or the least significant bit of byte 0
L562@P8: in the scratchpad, one bit at a time should shifted into the
L563@P8: shift register. After shifting in the 56th bit from the ROM or
L564@P8: the most significant bit of byte 7 from the scratchpad, the
L565@P8: polynomial generator will contain the recalculated CRC.
L566@P8: Next, the 8-bit ROM code or scratchpad CRC from the
L567@P8: DS18B20 must be shifted into the circuit. At this point, if
L568@P8: the re-calculated CRC was correct, the shift register will
L569@P8: contain all 0s. Additional information about the Maxim
L570@P8: 1-Wire cyclic redundancy check is available in Application
L571@P8: Note 27: Understanding and Using Cyclic Redundancy
L572@P8: Checks with Maxim iButton Products.

L590@P9: The 1-Wire bus system uses a single bus master to control one or more slave devices. The DS18B20 is always a
L591@P9: slave. When there is only one slave on the bus, the system is referred to as a “single-drop” system; the system is
L592@P9: “multidrop” if there are multiple slaves on the bus.
L593@P9: All data and commands are transmitted least significant
L594@P9: bit first over the 1-Wire bus.
L595@P9: The following discussion of the 1-Wire bus system is
L596@P9: broken down into three topics: hardware configuration,
L597@P9: transaction sequence, and 1-Wire signaling (signal types
L598@P9: and timing).
L599@P9: Hardware Configuration
L600@P9: The 1-Wire bus has by definition only a single data line.
L601@P9: Each device (master or slave) interfaces to the data line
L602@P9: via an open-drain or 3-state port. This allows each device
L603@P9: to “release” the data line when the device is not transmitting data so the bus is available for use by another device.
L604@P9: The 1-Wire port of the DS18B20 (the DQ pin) is open
L605@P9: drain with an internal circuit equivalent to that shown in
L606@P9: Figure 12.
L607@P9: The 1-Wire bus requires an external pullup resistor of
L608@P9: approximately 5kΩ; thus, the idle state for the 1-Wire
L609@P9: bus is high. If for any reason a transaction needs to be
L610@P9: suspended, the bus MUST be left in the idle state if the
L611@P9: transaction is to resume. Infinite recovery time can occur
L612@P9: between bits so long as the 1-Wire bus is in the inactive
L613@P9: (high) state during the recovery period. If the bus is held
L614@P9: low for more than 480µs, all components on the bus will
L615@P9: be reset.
